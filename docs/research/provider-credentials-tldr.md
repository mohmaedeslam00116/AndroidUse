# Provider credentials — TL;DR

Research: [#40](https://github.com/mohmaedeslam00116/AndroidUse/issues/40). Full report: [`provider-credentials.md`](provider-credentials.md). All sources retrieved 2026-10-22.

1. **Manus did not ship consumer subscriptions.** Manus Flex (2026-09-29) is bring-your-own-**API-key** with OpenRouter/Fireworks/Modal as initial partners; inference is still metered and billed to the provider. ([manus.im](https://manus.im/blog/introducing-manus-flex))
2. **OpenAI is the only vendor with a documented, tool-capable third-party path** onto a consumer plan ("Sign in with ChatGPT"): function/custom tools are supported, so ADR-0004's `act` schema fits. ([preview limitations](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations))
3. **…but it is gated:** open-source and locally-hosted apps may use it now, while a paid or remotely hosted app (AndroidUse's Relay) must join a "select group of commercial partners" via an interest form. ([request a client ID](https://developers.openai.com/siwc/request-client-id))
4. **Anthropic permits it only by arrangement:** host the *unmodified* Claude Code binary under Anthropic's Commercial ToS with each user on their own subscription, or obtain prior approval — "Anthropic does not allow third party developers to offer claude.ai login … including agents built on the Claude Agent SDK". ([legal and compliance](https://code.claude.com/docs/en/legal-and-compliance), [Agent SDK overview](https://code.claude.com/docs/en/agent-sdk/overview))
5. **Google forbids it, by name, twice** (Gemini CLI and Antigravity terms): third-party software using their OAuth "is a violation of applicable terms and policies" and grounds for suspension or termination. ([terms](https://geminicli.com/docs/resources/tos-privacy/), [Antigravity terms](https://antigravity.google/terms/))
6. **40 steps in 10 minutes is not rate-limited anywhere**; the real constraint is the user's *shared* allowance (Plus five-hour limit shared across all apps; Claude's five-hour and weekly limits shared with claude.ai), which the user cannot see per-action. ([accounts and sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions), [Claude plan limits](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-or-max-plan))
7. **No sanctioned path exposes a dollar cost.** Token counts exist (`usage.input_tokens`/`output_tokens`), but OpenAI says "don't use them to estimate included tasks" — so ADR-0006's `max_spend_usd` survives only as an *estimate*, and the enforceable signal becomes "the user is out of allowance", not "we spent $0.04 of $0.50". ([Codex pricing](https://developers.openai.com/codex/pricing))
